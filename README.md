# chatluna-plugin-image-host

ChatLuna v2 图床插件。在 WebUI 侧栏「图床」页面上传并分类管理图片，插件把图片地址清单注入提示词，Bot 用 v2 内置的 `<img>` 在回复中发送。所有设置都在该页面中修改。

## 功能

- **侧栏页面**：新建、重命名、删除分类，为分类填写描述；选择、拖入或粘贴上传图片，预览、重命名、移动到其他分类、删除图片，复制图片地址，把单张图片设为对 Bot 隐藏。
- **Bot 发图**：插件向 Bot 注入提示词，列出图片根地址以及 Bot 可见的分类、描述和文件名；提示词只提供图片清单，发送方式由 v2 内置提示词说明。
- **图片地址**：
  - `<图片根地址>/猫猫` 随机返回「猫猫」分类中的一张图片；
  - `<图片根地址>/猫猫/a.png` 返回指定图片，文件名可省略扩展名，英文不区分大小写。
  - 分类开启「只能随机」后，提示词只列出分类、不列文件名，指定图片地址返回 404；
  - 图片根地址形如 `http://192.168.1.2:5028/image-host/raw`，在「设置」标签中查看。
- **提示词可见可改**：页面「提示词」标签中编辑模板，`{url}` 替换为图片根地址，`{categories}` 替换为分类清单；右侧显示实际注入的内容，可一键恢复默认。每个分类可单独关闭「Bot 可见」，关闭后不写入提示词，图片地址返回 404；对 Bot 隐藏的单张图片同样不写入提示词、不参与随机，地址返回 404。
- **去重**：
  - 上传时按文件内容（SHA-256）判断，同一分类内已有相同图片时自动跳过并提示；移动图片到已有相同内容的分类会被拒绝。
  - 「分类内去重」「全部去重」清理直接放入目录造成的重复，每组保留最早的一张。
  - 随机地址按轮次洗牌：一轮内每张图片只返回一次，发完一轮再重新洗牌，且相邻两次不会是同一张。

## 设置

插件没有宿主配置项，设置在「图床」页面的「设置」标签中修改，保存后立即生效。分类的「Bot 可见」「只能随机」和图片的「对 Bot 隐藏」在「图片」标签中设置。提示词列出可见分类中的全部可见文件名，图片很多的分类建议设为「只能随机」。

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 注入提示词 | 开启 | 关闭后不注入提示词，Bot 不会得知图床中有哪些图片 |
| 图片访问地址 | 空 | 聊天平台下载图片使用的服务器地址；留空用 ChatLuna 服务器自身地址，平台不在同一台机器时填平台能访问的地址 |
| 单张大小上限（MB） | 10 | 上传单张图片的最大体积 |

图片由聊天平台按地址下载，不需要 `fs:read` 权限。图片地址不需要登录，只提供 Bot 可见的分类和图片；服务器对外开放时，隐藏的分类和图片不会被访问到。

## 存储

图片按 `data/chatluna/image-host/images/<分类>/<文件>` 存放（相对 ChatLuna 配置文件所在目录），目录即分类；`meta.json` 保存设置、分类描述、分类与图片的可见性、提示词模板和哈希缓存。直接向目录复制图片后，在页面点击「重新扫描」即可载入。

支持 PNG、JPEG、GIF、WebP、BMP，格式按文件内容识别。分类名和文件名不能包含空白和 `/ \ : * ? " < > | & '`，不能以 `.` 或 `-` 开头，最长 64 个字符。
