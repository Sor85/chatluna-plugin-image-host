# chatluna-plugin-image-host

ChatLuna v2 图床插件。在 WebUI 侧栏「图床」页面上传并分类管理图片，插件把图片清单注入提示词，Bot 用 v2 内置的 `<img>` 在回复中发送；聊天中也可以用指令直接发图。

## 功能

- **侧栏页面**：新建、重命名、删除分类，为分类填写描述；选择、拖入或粘贴上传图片，预览、重命名、移动到其他分类、删除图片。
- **Bot 发图**：插件向 Bot 注入提示词，列出图片根目录以及 Bot 可见的分类、描述和文件名；Bot 按描述挑选图片，写 `<img src="<图片目录>/猫猫/a.png"/>` 发送。
- **提示词可见可改**：页面「提示词」标签中编辑模板，`{dir}` 替换为图片根目录，`{categories}` 替换为分类清单；右侧实时显示实际注入的内容，可一键恢复默认。每个分类可单独关闭「Bot 可见」，关闭后只能通过指令使用。
- **指令发图**：发送 `/猫猫` 随机发送「猫猫」分类中的一张图片，发送 `/猫猫/a.png` 发送指定图片；文件名可省略扩展名，英文不区分大小写。分类不存在或与已有指令同名时不拦截消息。
- **去重**：
  - 上传时按文件内容（SHA-256）判断，同一分类内已有相同图片时自动跳过并提示；移动图片到已有相同内容的分类会被拒绝。
  - 「分类内去重」「全部去重」清理直接放入目录造成的重复，每组保留最早的一张。
  - 随机发图按轮次洗牌：一轮内每张图片只发一次，发完一轮再重新洗牌，且相邻两次不会是同一张。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 指令前缀 | `/` | `前缀+分类名` 随机发图，`前缀+分类名/文件名` 指定发图 |
| 注入提示词 | 开启 | 关闭后不注入提示词，Bot 不会得知图床中有哪些图片 |
| 提示词列出文件数 | 50 | 每个分类在提示词中列出的文件名上限，Bot 只能发送列出的图片；为 0 时只列分类 |
| 数据目录 | `data/chatluna/image-host` | 相对 ChatLuna 配置文件所在目录 |
| 单张大小上限（MB） | 10 | 上传单张图片的最大体积 |

Bot 读取本地图片需要 `fs:read` 权限；图片位于工作区外时无需额外的 `fs:outside` 权限（宿主对图片、音视频放行）。

## 存储

图片按 `<数据目录>/images/<分类>/<文件>` 存放，目录即分类；`meta.json` 保存分类描述、可见性、提示词模板和哈希缓存。直接向目录复制图片后，在页面点击「重新扫描」即可载入。

支持 PNG、JPEG、GIF、WebP、BMP，格式按文件内容识别。分类名和文件名不能包含空白和 `/ \ : * ? " < > | & '`，不能以 `.` 或 `-` 开头，最长 64 个字符。
